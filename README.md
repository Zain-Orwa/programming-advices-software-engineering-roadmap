# Programming Advices Software Engineering Roadmap

This repository documents my structured software engineering learning journey through the Programming Advices roadmap.

The goal is not only to store code, but to build a professional learning archive that shows my progress, problem-solving 
process, mistakes, improvements, and projects from foundations to backend development.

---

## About This Repository

This repository is my long-term software engineering learning archive.

It follows the Programming Advices roadmap and documents my progress through:

- Programming foundations
- Algorithms and problem solving
- C++
- Object-oriented programming
- Data structures
- Databases
- C#
- .NET backend development
- Web/mobile specialization

The focus is not only on writing code, but also on understanding concepts deeply, solving problems step by step, 
documenting mistakes, and improving solutions over time.

---

## Learning Philosophy

For every important topic, exercise, or project, I try to document:

- The problem requirements
- The concepts used
- My solution approach
- Mistakes and edge cases
- Possible improvements
- Final result

This repository is designed to show how I think, not only what I coded.
